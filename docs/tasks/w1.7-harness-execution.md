## Resumen operativo

**Objetivo:** producir tests comparables del PEF Core, sus modos offline, persistencia y recuperación para W1.8. **Subtasks principales:** escenario/fault injection, evidencia verificable, reliability, workload/security y gating estadístico. **DoD diseño:** IDs estables, estímulos, oráculos de PASS, medidas, adaptadores y evidencia; pruebas físicas pendientes. **Dependencias:** runtime W1.6 y hardware para pruebas que no pueden simularse.

## Exit semantics

Status `SPECIFIED` = plan versionado, `EXECUTABLE` = adapter implemented, `PASS` = run evidence verified, `BLOCKED` = missing precondition/driver, `FAIL` = oracle violated, `ERROR` = harness failure, `NOT_RUN` = not attempted. **No evidence = no PASS.**
