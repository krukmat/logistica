- **B3 — Storage matrix · CLOSED (software/lab, CI VERIFIED):** fault-injected host-fs write/fsync port, 11 deterministic checks (34 total) against the shared LocalReceipts Core, host files and real fsync.

- **B4 — Golden traces · CLOSED (software/lab, CI VERIFIED):** pinned independent fixture and reusable shared-Core trace runner; macOS CLI ↔ Linux CI report parity, dashboard UI/HTTP, advisory timing/RSS only.
