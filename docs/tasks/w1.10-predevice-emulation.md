# W1.10 — Emulator → device friction reduction (1–2 subtask levels)

W1.9.T software/lab is closed. This plan keeps **one Product Core** for Property/Host and explicitly separates lab results from physical acceptance.

## W1.10.A — Hardware port contract rehearsal · IMPLEMENTED / CI PENDING

- **A1 — Versioned port contract:** WAN probe/link vs upstream, route application, journal ACK and negative cases; deterministic, host-safe fault injection.
- **A2 — Core behavioral conformance:** 13 checks for failover, local-only, malformed probe, route rejection, recovery/hysteresis, offline P1 receipt, dedup/conflict, reopen, and false ACK.
  - **A2.a — Assertion lock:** tests compare IDs with the machine-readable contract to avoid silently dropping a case.
- **A3 — Operator-visible emulator:** authenticated dashboard action, per-check evidence and CLI command, no device backend fallback.
- **A4 — Test/CI:** HTTP E2E, Node tests, workflow JSON evidence artifact.

**Dependencies:** W1.9.R/S/T. **DoD:** same Core exercised; UI/API E2E PASS; 13 contract checks PASS and CI green; hardware always BLOCKED. **Risk:** route refusal fixture injects *before* mutation, so partial OS mutations remain unhandled.

## W1.10.B — Port hardening · PLANNED
- **B1 — Bounded ports:** probe/route deadlines, hanging calls, cancellation semantics, safe reconciliation of uncertain/partial route commits.
- **B2 — Storage matrix:** ENOSPC, short write, corruption, power-interruption simulation, metadata migration and quota/backpressure.
  - **B2.a — Physical distinction:** OS fsync/simulated powercut is not physical durability evidence.
- **B3 — Golden traces:** stable trace comparison Mac ↔ Linux CI ↔ future device, capture resource/latency but never extrapolate to watts.

## W1.10.C — Physical qualification preparation · PLANNED / DEVICE BLOCKED
- **C1 — Driver/provisioning:** Linux network/route authority, storage, trust/PKI and watchdog/OTA; no platform chosen.
- **C2 — Device acceptance:** NIC faults, measured CPU/RAM/throughput/thermal/power, power cut, installation time, BOM/TCO → W1.8.E–G.
- **C3 — Gate:** promote `device` only with physical evidence, independent of W1.10 software PASS.
