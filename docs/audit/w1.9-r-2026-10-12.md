## R1 — Product Core owns decisions (PASS)

`src/core/wan-policy.js` is called by BOTH `src/emulator/core.js` and `src/core/connectivity-controller.js`, with no sim-to-controller dependency. 128 deterministic transition vectors compare primary/backup selection, hysteresis, all-WAN-down `LOCAL_ONLY` and logical clock between simulator and adapter controller. A route-writer exception does not create a false committed route observation.

`src/core/edge-runtime.js`, `local-receipts.js`, `event-envelope.js`, `cloud-sync.js` no longer import the emulator; IO is passed via ports. A test imports Core directly with a fully in-memory journal to prove it does not require the OS filesystem or the dashboard.

## R2 — Actual adapter and backend integration (PASS)

`src/runtime/edge-service.js` composes the Core with a journal and route/probe ports. `src/adapters/os-file-journal.js` owns Node fsync; `src/adapters/linux-netns-ports.js` owns sandbox kernel route actions. Legacy `src/emulator/lab` imports remain small compatibility shims. The runtime registry offers `virtual-lab` and `linux-lab`; `device` **returns BACKEND_NOT_IMPLEMENTED**. The synchronous scenario runner retains `sim` mode only, and explicitly marks the other kinds blocked rather than invoking network privileged actions.

## R3 — Dashboard lifecycle independence (PASS)

`createDashboardServer({runtimeLab})` accepts an externally owned lab runtime. E2E test: start Control Panel, register receipt, close server, restart Control Panel with same runtime, verify receipt persisted; then close runtime explicitly and verify temporary filesystem cleanup. Default local dashboard still creates its own lab for usability. The UI displays `virtual-lab / shared PEF Core`.

## R4 — Correct durability and contract gate (PASS)

Intentional bad journal port returning `ack=true` but `fsyncCompleted=false` is rejected for local receipt, WAN event and Cloud cursor persistence. Code does not claim a durable result for uncommitted evidence. Registry `docs/contracts/emulator-integration-v1.json` marks R as UI-integrated, and `test/dashboard-integration-gate.test.js` requires the new feature to remain visible and tested.

## Not established

- A production Linux NIC/ISP driver, routing/NAT/DHCP/firewall integration, packet loss or p95 throughput performance.
- Bootable appliance, systemd service, hardware watchdog, driver access privileges, secure boot/OTA, PKI/mTLS or device identity.
- Real SSD/controller power-loss durability and workload process/container isolation.
- Microcontroller portability; shared Core is JavaScript/Node 20+ rather than a language-neutral executable.
- All modeled workload admission and recovery behaviors as independent product services; these remain emulation-only.
