## Architecture preserved

No new business-rule/Core variant. `src/adapters/os-file-journal.js` retains real host fsync/default `node:fs`. Trusted in-process `fsOps` supports deterministic synthetic failures without modifying operator or production storage; `src/adapters/faultable-file-ops.js` injects faults only for lab use. The exact `src/core/local-receipts.js` uses the journal ACK gate; no fake local ACKs allowed. Dashboard’s existing authenticated `predeviceConformance` action and HTTP test cover all cases, and CLI emits per-check JSON evidence.

Test cases:
1. `STORAGE_ENOSPC_FAIL_CLOSED`: good receipt retained, full/unsafe fails closed.
2. `STORAGE_PARTIAL_WRITE_QUARANTINE`: torn tail, no ACK, boot rejected (no auto repair).
3. `STORAGE_ZERO_WRITE_NO_ACK`: zero bytes cannot imply durable ACK.
4. `STORAGE_FSYNC_AMBIGUITY_IDEMPOTENT_RECOVERY`: no initial ACK, event may exist after reopen, duplicate/ID conflict safe.

7. `STORAGE_TRUNCATED_TAIL_BLOCKED`: incomplete final record rejected.
8. `STORAGE_COMPACTION_PRE_RENAME_RECOVERY`: original committed state recoverable.
9. `STORAGE_COMPACTION_POST_RENAME_RECHECK`: reopen retained ACK and pending.
10. `STORAGE_LEGACY_METADATA_MIGRATION`: unversioned format to explicit v1 via compaction; event hash stable.
11. `STORAGE_FUTURE_SCHEMA_REFUSED`: unsupported on-disk metadata rejected.

## Remaining physical and operational risks

Injected ENOSPC/EIO are logical `node:fs` port faults; they do **not** fill a real disk or simulate kernel writeback caching/disk barriers. Pre/post rename `testHook` is an exception during execution, not a power interruption. Real power-cycle tests, dirty-page durability, flash wear, journaling FS options, readonly remount, partition exhaustion, board watchdog, hardware rollback/version upgrades and crash-consistent secure metadata remain `NOT_RUN`. Unknown schema is refused, but v1 schema marker is not a separately authenticated signature; the event data sha256 is unchanged specifically to keep Cloud replay fingerprint semantics intact. Single writer remains a precondition. Unsafe/torn tails require supervised preservation/recovery, not automatic truncate.
