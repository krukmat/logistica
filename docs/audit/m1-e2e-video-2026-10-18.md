## Interpretation and boundaries

The normal test bundle and optional video bundle come from different *legitimate* M1 scenario executions; the video itself **only** displays the events of the same execution packaged alongside it. It is an animated, read-only software evidence timeline recorded from an HTML viewer using Playwright, **not** uncut external-camera footage or direct physical-device observation.

The test uses Node localhost real network API and real host OS journal `fsync`, with actual process SIGKILL. **WAN interfaces are synthetic**, remote Cloud is an **in-memory mock** with ephemeral proof key, not Cloud Lite, the Linux CI runner is not 1 GiB constrained, and there was **no physical powercut or device validation**.
