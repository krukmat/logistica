## Implemented and CI tested

- `src/adapters/bounded-wan-ports.js`: explicit configurable probe, apply-route and reconcile deadlines, cooperative `AbortSignal`; no Product Core changes.
- Timed-out probes return an error without committing WAN state.
- A route operation that times out **retains a quarantine**, even if its underlying Promise later completes and mutates the synthetic route. New route changes are rejected until the operation settles and explicit external state readback confirms the trusted expected route.
- A route that never settles cannot be reconciled or operated through this adapter within that process.
- New adapter instances require explicit boot reconciliation before first route write; mismatch cannot unlock the adapter.
- Lab matrix includes six B2 checks: `PORT_BOOT_ROUTE_RECONCILIATION`, `PORT_PROBE_DEADLINE_NO_COMMIT`, `PORT_LATE_ROUTE_QUARANTINE`, `PORT_LATE_COMMIT_REQUIRES_REPAIR`, `PORT_COOPERATIVE_ABORT_RECHECK`, `PORT_HUNG_ROUTE_REMAINS_BLOCKED`.
- Existing dashboard action executes all 23 checks and exposes `physicalValidated:false`, `deviceBackend:BACKEND_NOT_IMPLEMENTED`.

## Risk boundary / open constraints

All timing failures run on in-memory synthetic ports, not on Linux kernel route commands. `AbortSignal` is advisory, not proof a subprocess/OS operation stopped. Reconciliation is in-process and uses a test-supplied expected route; no trustworthy persistent physical boot record or orphan OS process fencing is implemented. A process crash and restart can leave an old subprocess operating afterward; **this remains a production blocking risk**. No real NIC, WAN physical failure, carrier throughput, cloud PKI, powercut persistence, installed watchdog or device boot tested. Software fsync is not physical storage durability. Hardware `device` remains `BACKEND_NOT_IMPLEMENTED`, production and SKU selection not approved.

**Verdict:** W1.10.B2 **CLOSED in software/lab only**, gate permits device integration work, not field/production usage. Next W1.10.B3 storage fault matrix and W1.10.B4 trace portability.
