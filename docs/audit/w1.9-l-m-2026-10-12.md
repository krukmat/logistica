## Technical slice and ownership

`createEdgeRuntime` injects `probe` and `applyRoute` into the existing `createConnectivityController`, then appends selection/connectivity changes to the OS-file journal. The event carries a correlation ID, logical time, selected WAN, probes and a claim that the injected route adapter **returned successfully**. `fsync` is performed before the journal ACK. If persistence fails, the control-plane/routing path must not pretend that an ACK succeeded: the runtime marks `DEGRADED`, queues retry events **volatily and bounded**, and records dropped-evidence counters.

The scenario uses namespaces and veth exclusively in the ephemeral GitHub-hosted runner and a temporary journal directory. There are no device changes or production deployment.
